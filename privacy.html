Privacy Policy — Cyber Shorts Publisher

Effective date: October 22, 2026

1. Overview

Cyber Shorts Publisher ("the Application") is a personal, single-owner automation tool. It uploads short educational videos about cybersecurity and secure programming to the owner's own YouTube channel through the YouTube Data API. The Application is not a public service and is not used by any third party.

2. Data the Application accesses

With the owner's authorization, the Application uses one Google API scope only: https://www.googleapis.com/auth/youtube.upload. This scope allows the Application to upload videos to the owner's own YouTube channel. The Application does not read, collect, or process personal data of any other person, and it does not access the owner's other Google data (such as email, files, contacts, or calendar).

3. Data storage

The OAuth credentials and refresh token generated by the owner's authorization are stored on the owner's own private server, in a permission-restricted file, solely so the Application can perform the scheduled uploads the owner configured. Video files, titles, and descriptions uploaded through the Application are prepared by the owner and stored on the owner's own server.

4. Data sharing

The Application does not sell, rent, share, or transfer any data to third parties. The only data transmitted is the video content and metadata the owner prepared, sent to YouTube through Google's official API as part of the upload the owner requested.

5. Revoking access

The owner can revoke the Application's access at any time from the Google Account security settings (Third-party access) or by deleting the stored credentials on the owner's server, which immediately stops all uploads.

6. YouTube API Services

The Application uses YouTube API Services. By using those services it is also subject to the YouTube Terms of Service and the Google Privacy Policy.
