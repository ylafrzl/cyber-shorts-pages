Cyber Shorts Publisher

Personal automation tool for publishing short educational videos about cybersecurity and secure programming.

About

Cyber Shorts Publisher is a private, single-owner automation application. It uploads short-form educational videos (YouTube Shorts) about cybersecurity, programming security, and DevSecOps to the application owner's own YouTube channel using the official YouTube Data API.

The application is not a public service. It is not offered to, and cannot be used by, any third party. Only the owner authorizes the application, and it only ever accesses the owner's own channel.

What the application does

On a daily schedule, the application uploads pre-produced educational videos to the owner's YouTube channel with titles, descriptions, and sources prepared by the owner. It uses a single YouTube API scope: youtube.upload.
